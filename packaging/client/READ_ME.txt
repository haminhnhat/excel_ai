EXCEL AI CONTROLLER - PORTABLE CLIENT

1. Giai nen TOAN BO file ZIP vao thu muc ban co quyen ghi, vi du Documents.
   Khong mo app ngay ben trong ZIP. Khong dat app trong Program Files.
2. Mo "Excel AI Controller.bat". Trinh duyet se tu mo khi app san sang.
3. Giu cua so app dang mo trong khi su dung.
4. Khi xong, nhan Ctrl+C trong cua so app de dung server, roi dong trinh duyet.

Khong can cai Python, pip hoac thu vien. Khong can quyen Administrator.
Yeu cau: Windows 10/11 x64 va Microsoft Excel desktop da cai dat/kich hoat.
Excel Online khong thay the duoc Excel desktop cho tinh lai cong thuc.

App kem workbook va profile da duoc nguoi cung cap cau hinh. Chi gui cho nguoi duoc
phep nhan du lieu workbook. Khong dua goi nay len GitHub public.
File Excel xuat ra nam trong outputs; file goc nam trong models.
Khong xoa/doi ten runtime, app, web, config, models hoac .env.

Mac dinh app chay tren may nay (127.0.0.1), khong mo cho mang LAN.
Neu cong 8000 dang ban, app tu chon cong tiep theo; xem URL trong cua so app.
Che do AI_PROVIDER=mock la bo phan tich lenh cuc bo, khong phai LLM online.
Khong can Internet/API key cho che do mac dinh.

Neu app bi loi: gui anh loi va file trong logs cho nguoi ho tro.
Neu Windows/antivirus canh bao, kiem tra nguon gui voi nguoi cung cap;
khong tat antivirus. Goi nay khong duoc ky so.

Python va thu vien ben thu ba duoc kem theo de chay doc lap.
Thong tin phien ban: build-info.json, requirements-portable.txt.
Giay phep ben thu ba nam trong runtime/LICENSE.txt va cac thu muc
runtime/Lib/site-packages/*.dist-info (va thu muc license tuong ung).
Goi nay khong chua cong cu License Admin, private key hay API key.
